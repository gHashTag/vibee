## 🎨 Хочешь обучить свою ИИ-модель?

### Способ 1: Кнопки (рекомендуется)
1. Нажми "**🎨 Обучение модели**" в главном меню
2. Выбери качество (⚡ Быстро / 🔥 Стандартно / 💎 Качественно)
3. Выбери количество шагов (1-50)
4. Подтверди и отправь фото!

### Способ 2: Текст
Просто напиши:
- "**обучение**"
- "**модель**"
- "**создать лицо**"
- "**хочу модель**"
