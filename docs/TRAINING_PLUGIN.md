## 🎯 Обзор

Training Plugin позволяет пользователям обучать персональные LoRA модели через Telegram бота.

### Что это делает?

1. **Собирает фото** пользователя из Telegram
2. **Создаёт ZIP-архив** из фотографий
3. **Отправляет на обучение** в fal.ai
4. **Возвращает готовую модель** для генерации изображений

### Возможности

- ✅ Автоматический сбор фото из Telegram
- ✅ Геймифицированный UX с прогресс-баром
- ✅ Выбор качества обучения (fast/normal/max)
- ✅ Интерактивные подсказки
- ✅ Мотивационные сообщения
- ✅ Нет необходимости в S3 (использует Telegram Bot API)

## 📱 Команды

### `/train help` или `/train`

Показывает полную справку по использованию.

**Пример:**
```
Пользователь: /train
Бот: 🎨 Обучение персональной ИИ-модели...
```

---

### `/train start <название> <триггер> [качество]`

Начинает процесс обучения модели.

**Параметры:**
- `<название>` - имя модели (на русском/английском)
- `<триггер>` - триггерное слово для генерации (латиница, lowercase)
- `[качество]` - опционально: `fast`, `normal` (default), `max`

**Примеры:**

```bash
# Обычное качество (2500 шагов, 15-30 мин)
/train start МоёЛицо my_face

# Быстро (1000 шагов, 10-15 мин)
/train start МоёЛицо my_face fast

# Максимум (5000 шагов, 30-60 мин)
/train start МоёЛицо my_face max
```

**Что происходит дальше:**
1. Бот создаёт сессию обучения
2. Просит отправить 10-20 фото
3. Показывает прогресс после каждого фото

---

### `/train confirm`

Завершает сбор фото и запускает обучение.

**Требования:**
- Минимум 10 фото загружено
- Максимум 30 фото
- Активная сессия обучения

**Процесс:**
1. 📦 Создание ZIP (10-30 сек)
2. 📤 Загрузка на file.io
3. 🚀 Отправка на fal.ai
4. ⏱️ Ожидание обучения (15-60 мин)

**Пример:**
```
Пользователь: /train confirm
Бот: 📦 Создаю архив из 15 фотографий...
```

---

### `/train cancel`

Отменяет текущую сессию обучения.

**Пример:**
```
Пользователь: /train cancel
Бот: ✅ Сессия обучения "МоёЛицо" отменена.
     Собрано было: 12 фото
```

## ⚙️ Параметры обучения

### Качество обучения

| Качество | Steps | Learning Rate | Время | Когда использовать |
|----------|-------|---------------|-------|-------------------|
| `fast` 🏃 | 1000 | 0.0004 | 10-15 мин | Быстрый тест, demo |
| `normal` ⭐️ | 2500 | 0.00009 | 15-30 мин | **Рекомендуется** для большинства |
| `max` 👑 | 5000 | 0.00009 | 30-60 мин | Максимальное качество |

### fal.ai API Parameters

```typescript
{
  // Входные данные
  images_data_url: string,      // URL ZIP-архива с фото
  trigger_phrase: string,        // Триггерное слово

  // Параметры обучения
  steps: number,                 // 1000-5000 (default: 2500)
  learning_rate: number,         // default: 0.00009 для portrait

  // Дополнительные
  output_format: 'safetensors', // Формат модели
}
```

### Рекомендации по фото

**Что нужно:**
- ✅ 10-20 фотографий лица
- ✅ Разные ракурсы (анфас, профиль, 3/4)
- ✅ Разное освещение (естественное, искусственное)
- ✅ Разные эмоции (улыбка, серьёзное лицо, и т.д.)
- ✅ Разный фон
- ✅ Хорошее качество (не размытые)

**Что НЕ нужно:**
- ❌ Групповые фото (только ваше лицо!)
- ❌ Солнечные очки, маски
- ❌ Размытые или тёмные фото
- ❌ Слишком далёкие снимки
- ❌ Одинаковые ракурсы

## 🔧 API Reference

### Services

#### PhotoCollectorService

Управляет сессиями сбора фото.

```typescript
class PhotoCollectorService extends Service {
  // Создать сессию
  createSession(userId: string, faceName: string, triggerWord: string): TrainingSession

  // Получить активную сессию
  getActiveSession(userId: string): TrainingSession | null

  // Добавить фото
  addPhoto(userId: string, fileId: string, filePath: string, fileSize: number): number

  // Завершить сессию
  completeSession(userId: string): TrainingSession | null

  // Отменить сессию
  cancelSession(userId: string): void
}
```

#### ZipService

Создаёт ZIP-архивы из Telegram фото.

```typescript
class ZipService extends Service {
  // Создать ZIP из фото Telegram
  createZipFromTelegramPhotos(
    photos: Array<{ fileId: string; filePath: string }>,
    sessionId: string
  ): Promise<string>

  // Загрузить на file.io
  uploadToFileIo(zipPath: string): Promise<string>
}
```

## 🐛 Troubleshooting

### "Сервисы обучения не инициализированы"

**Проблема**: Плагин не загружен или сервисы не запустились.

**Решение**:
1. Проверь что `trainingPlugin` добавлен в `character.ts`
2. Проверь логи запуска на ошибки
3. Убедись что все зависимости установлены: `bun install`
4. Перезапусти бота: `bun run build && bun run dev`

---

### "FAL_KEY not found"

**Проблема**: Отсутствует ключ fal.ai.

**Решение**:
1. Получи ключ на https://fal.ai
2. Добавь в `.env`: `FAL_KEY=your-key-here`
3. Перезапусти бота

---

### "Failed to upload to file.io"

**Проблема**: file.io недоступен или ограничения.

**Решение**:
1. Попробуй ещё раз через 5 минут
2. Проверь размер ZIP (должен быть < 100MB)
3. Альтернатива: можно использовать transfer.sh (требует изменения кода)

---

### Фото не сохраняются

**Проблема**: TelegramPhotoService не слушает события.

**Решение**:
1. Проверь логи: должно быть `[TelegramPhotoService] ✅ Initialized`
2. Убедись что есть активная сессия (`/train start` выполнен)
3. Отправляй фото как фото (не файлы!)

---

### "Недостаточно фотографий"

**Проблема**: Меньше 10 фото загружено.

**Решение**:
1. Загрузи ещё фото
2. Проверь что фото действительно загружаются (должны быть сообщения прогресса)
3. Используй `/train cancel` и начни заново

```
┌─────────────────────────────────────────┐
│         Telegram Bot (User)             │
└─────────────────┬───────────────────────┘

                  ▼
┌─────────────────────────────────────────┐
│     TelegramPhotoService                │
│  (Слушает TELEGRAM_MESSAGE_RECEIVED)    │

                  ▼

│    PhotoCollectorService                │
│   (Хранит сессии и фото в памяти)      │
└─────────────────┬───────────────────────┘
                  │
                  ▼
┌─────────────────────────────────────────┐
│         trainLoraAction                 │

└─────────────────┬───────────────────────┘

                  ▼

│           ZipService                    │
```
