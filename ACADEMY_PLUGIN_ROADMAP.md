### 1️⃣ **Vector Database Plugin** 🔥 ПРИОРИТЕТ 1
**Файл:** `src/academy/vector-db-plugin.ts`

**Функции:**
- Векторизация всех markdown файлов курсов
- Сохранение в векторную базу (Supabase/Neon)
- Семантический поиск по содержимому
- Быстрый поиск ответов на вопросы

**Технологии:**
- OpenAI Embeddings API
- Supabase Vector (pgvector)
- Обработка markdown → embeddings

**Команды:**
```

/search <запрос> - найти информацию
```

## 🔧 Технические Детали

### База Данных
```sql
-- Таблица курсов
CREATE TABLE courses (
  id UUID PRIMARY KEY,
  title TEXT NOT NULL,
  description TEXT,
  category TEXT,
  lessons JSONB
);

-- Таблица векторных эмбеддингов
CREATE TABLE lesson_embeddings (
  id UUID PRIMARY KEY,
  course_id UUID REFERENCES courses(id),
  lesson_path TEXT,
  content TEXT,
  embedding VECTOR(1536),
  created_at TIMESTAMP DEFAULT NOW()
);

-- Таблица прогресса пользователей
CREATE TABLE user_progress (
  user_id TEXT,
  course_id UUID REFERENCES courses(id),
  lessons_completed TEXT[],
  score INTEGER,
  updated_at TIMESTAMP DEFAULT NOW()
);
```
