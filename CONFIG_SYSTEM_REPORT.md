## 🚀 Использование

### Базовый пример
```typescript
import { configManager } from './plugins/core';

// Загрузить конфигурацию
const config = await configManager.loadConfig('neuro-photo');

// Проверить плагин
if (configManager.isPluginEnabled('ai-tutor-service')) {
  const aiConfig = await configManager.loadConfig('ai-tutor-service');
}

// Валидировать все
const results = await configManager.validateAll();
```

### Работа с секретами
```typescript
import { getSecret, resolveEnvVars } from './plugins/core';

// Получить секрет
const token = getSecret('TELEGRAM_BOT_TOKEN');

// Подставить переменные
const config = resolveEnvVars({
  apiKey: '${OPENROUTER_API_KEY}',
  url: 'https://api.example.com'
});
```
