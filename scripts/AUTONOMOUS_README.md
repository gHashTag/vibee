# 🌈 РАДУЖНЫЙ МОСТ - Autonomous Scripts

## Цель: Полностью Автономная Разработка

**Проблема:** Бот НЕ может разрабатывать и тестировать без участия человека.

**Решение:** Autonomous Telegram UserBot через StringSession.

## Архитектура

```
🌈 РАДУЖНЫЙ МОСТ Autonomous System
├── Session Management (ОДИН РАЗ)
│   └── autonomous-telegram-auth.py
│       ├── Создает StringSession
│       ├── Сохраняет в .env
│       └── Больше никогда не нужна авторизация!
│
├── Bot Controller (АВТОНОМНО)
│   └── autonomous-telegram-bot.py
│       ├── Отправляет сообщения боту
│       ├── Читает ответы
│       └── Запускает тесты
│
└── Orchestrator (ПОЛНЫЙ ЦИКЛ)
    └── rainbow-bridge-autonomous.sh
        ├── Проверяет session
        ├── Запускает бота
        ├── Тестирует
        ├── Анализирует
        ├── Разрабатывает фиксы
        └── Коммитит изменения
```

## Быстрый Старт

### Шаг 1: Создать Session String (ОДИН РАЗ!)

```bash
cd /Users/playra/vibee

python3 scripts/autonomous-telegram-auth.py
```

**Что произойдёт:**
1. Скрипт подключится к Telegram
2. Telegram отправит код подтверждения в приложение
3. Введи код из Telegram
4. Session string сохранится в `.env` автоматически

**ВАЖНО:** Это нужно сделать ОДИН РАЗ! После этого бот может работать вечно без твоего участия.

### Шаг 2: Запустить Автономный Цикл

```bash
./scripts/rainbow-bridge-autonomous.sh
```

**Что произойдёт:**
1. ✅ Проверит session (создаст если нужно)
2. ✅ Запустит бота (если не запущен)
3. ✅ Дождётся инициализации
4. ✅ Отправит `/selftest` автономно
5. ✅ Прочитает результаты
6. ✅ Проанализирует ошибки
7. ✅ Разработает фиксы (TODO)
8. ✅ Закоммитит изменения (TODO)

**БЕЗ ТВОЕГО УЧАСТИЯ!**

## Troubleshooting

### Session string недействителен

**Проблема:** `Session недействителен! Запусти autonomous-telegram-auth.py`

**Решение:**
```bash
# Удали старый session
sed -i '' '/TELEGRAM_SESSION_STRING/d' .env

# Создай новый
python3 scripts/autonomous-telegram-auth.py
```

### Бот не инициализируется

**Проблема:** Бот запустился, но не инициализировался за 60 сек

**Решение:**
```bash
# Проверь логи
tail -100 /tmp/vibee-autonomous.log

# Убей старые процессы
pkill -f "bun run dev"

# Запусти заново
./scripts/rainbow-bridge-autonomous.sh
```

### telethon не установлен

**Проблема:** `ModuleNotFoundError: No module named 'telethon'`

**Решение:**
```bash
pip3 install telethon python-dotenv
```

### Telegram заблокировал аккаунт

**Проблема:** `Too many auth attempts`

**Решение:**
1. Подожди 24 часа (Telegram снимет блок)
2. НЕ пытайся авторизоваться снова!
3. После разблокировки - запусти `autonomous-telegram-auth.py` ОДИН РАЗ

## Как Это Работает

### StringSession

**Обычная авторизация (плохо):**
```
Каждый запуск → Запрос кода → Ввод вручную → ❌ НЕ автономно
```

**StringSession (хорошо):**
```
Один раз:
  1. Создать session → Ввести код
  2. Сохранить session string в .env

Потом ВЕЧНО:
  1. Прочитать session string из .env
  2. Работать автономно → ✅ АВТОНОМНО!
```

### Автономный Цикл

```
1. CHECK SESSION
   ├── Есть в .env? → Валиден? → ✅
   └── Нет? → Создать → Сохранить → ✅

2. START BOT
   ├── Запущен? → ✅
   └── Не запущен? → Запустить → Ждать init → ✅

3. SEND /selftest
   ├── Подключиться к Telegram (StringSession)
   ├── Найти бота (@agent_vibecoder_bot)
   ├── Отправить /selftest
   └── Прочитать ответ → ✅

4. ANALYZE RESULTS
   ├── Парсинг ответа бота
   ├── Проверка "✅ все тесты пройдены"
   └── Логирование результатов → ✅

5. DEVELOP FIXES (если нужно)
   ├── Анализ ошибок
   ├── Генерация фиксов (Claude Code)
   ├── Применение изменений
   └── Коммит → ✅

6. REPEAT
   └── Каждые N минут → ✅
```
