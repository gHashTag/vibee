## 🔧 Архитектура интеграции

### Поток обработки TTS:
```
1. Пользователь отправляет команду или текст
2. Telegram плагин получает сообщение
3. TTS плагин определяет язык текста
4. Выбирает подходящий голос из VOICE_MAP
5. Отправляет запрос в FAL.ai API (playai/tts/v3)
6. Генерирует аудиофайл
7. Сохраняет в кэш (локально)
8. Отправляет аудио пользователю в Telegram
```

### Ключевые файлы:
- `src/character.ts` - конфигурация plugins и secrets
- `.env.local` - локальные переменные (FAL_API_KEY)
- `node_modules/@elizaos/plugin-tts/` - код плагина
