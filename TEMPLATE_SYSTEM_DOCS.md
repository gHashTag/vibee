# 📝 Система Пользовательских Шаблонов Подсказок

## Обзор

Система шаблонов позволяет пользователям создавать собственные подсказки для взаимодействия с ботом. Это мощный инструмент для персонализации общения!

## 🎯 Основные Возможности

### 1. **Создание Шаблонов**
Пользователи могут создавать шаблоны с переменными:
```
Название: "Объяснение кода"
Содержимое: "Привет! Объясни {topic} простыми словами для {level}."
Переменные: topic, level
```

### 2. **Система Переменных**
Поддерживаемые переменные в фигурных скобках:
- `{name}` - имя пользователя
- `{topic}` - тема разговора
- `{style}` - стиль ответа
- `{level}` - уровень сложности
- Любые другие пользовательские переменные

### 3. **Интерактивное Создание**
Диалоговый режим создания:
1. Ввод названия
2. Ввод описания
3. Ввод содержимого с переменными

## 🚀 Команды

### `/template create`
Создать новый шаблон
```bash
/template create МоёНазвание
```

### `/template list`
Показать все шаблоны пользователя
```bash
/template list
```

### `/template preview <имя>`
Посмотреть детали шаблона
```bash
/template preview ОбъяснениеКода
```

### `/template use <имя>`
Использовать шаблон (запросит переменные)
```bash
/template use ОбъяснениеКода
```

### `/template edit <имя>`
Редактировать существующий шаблон
```bash
/template edit ОбъяснениеКода
```

### `/template delete <имя>`
Удалить шаблон
```bash
/template delete ОбъяснениеКода
```

### `/template help`
Показать справку
```bash
/template help
```

## 📚 Примеры Использования

### Пример 1: Объяснение кода
```
Название: "Объяснение кода"
Содержимое: "Привет! Объясни {topic} простыми словами для {level}. Используй стиль {style}."
```
**Использование:**
```
/template use Объяснение кода
→ Введи значение для {topic}: closures в JavaScript
→ Введи значение для {level}: начинающий
→ Введи значение для {style}: дружелюбный
```

### Пример 2: Code Review
```
Название: "Code Review"
Содержимое: "Привет! Сделай code review кода:\n```{code}```\nВ стиле {style}."
```
**Использование:**
```
/template use Code Review
→ Введи значение для {code}: function sum(a, b) { return a + b; }
→ Введи значение для {style}: конструктивный
```

### Пример 3: Создание TODO
```
Название: "TODO List"
Содержимое: "Создай TODO список для проекта {project} на {duration}. Учти сложность: {level}."
```

## 🔧 Архитектура

### Классы

#### `TemplateService`
Основной сервис управления шаблонами:
- Создание/редактирование/удаление шаблонов
- Применение шаблонов с переменными
- Извлечение переменных из контента

#### `Template`
Интерфейс шаблона:
```typescript
interface Template {
  id: string;
  userId: string;
  name: string;
  description: string;
  content: string;
  variables: string[];
  createdAt: number;
  updatedAt: number;
}
```

#### `TemplateCommandsService`
Обработчик команд:
- `/template create` - интерактивное создание
- `/template list` - просмотр списка
- `/template use` - применение с переменными
- И другие команды

### Файловая Структура
```
src/template/
├── TemplateService.ts        # Основной сервис
└── template-plugin.ts        # Плагин с командами
```
