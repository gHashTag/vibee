Плагин запускается, но много ошибок БД:
```
❌ Failed to create table
❌ Failed to save news
❌ Failed to send news
```

**Возможные причины:**
1. БД еще не инициализирована когда запускается сервис
2. Неправильный путь к БД
3. Проблемы с правами доступа
4. Chat ID не настроен

### **Решение**
Нужно добавить проверку доступности БД перед операциями:
```typescript

  }
  // ... остальной код
```
