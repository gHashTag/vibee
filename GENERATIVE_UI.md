# 🎨 Generative UI для Telegram бота Vibee

## Что это такое?

**Generative UI** - это система автоматической генерации интерактивных элементов интерфейса (кнопки, меню, формы) на основе контекста разговора с AI агентом.

Вместо того чтобы вручную программировать каждую кнопку, AI агент **сам решает**, какие UI элементы нужны пользователю прямо сейчас!

---

## 🚀 Что умеет наш Generative UI

### 1️⃣ **Inline Callback Buttons** (кнопки с обработчиками)

```typescript
{
  type: 'inline_callback',
  text: '🚀 Начать обучение',
  callback_data: 'start_course'
}
```

**Когда генерируется:**
- Когда пользователь спрашивает про обучение
- Когда нужно выбрать из вариантов
- Когда требуется подтверждение действия

**Пример в чате:**
```
User: Хочу изучить vibe-coding
Bot: Отлично! Vibe-coding - это про скорость и кайф от разработки...

[🚀 Да, начнём!] [📚 Покажи ресурсы]
```

---

### 2️⃣ **URL Buttons** (кнопки со ссылками)

```typescript
{
  type: 'inline_url',
  text: '📖 Документация',
  url: 'https://docs.elizaos.ai'

```

**Когда генерируется:**
- При упоминании внешних ресурсов

**Когда генерируется:**
- При выборе инструментов
- Для быстрого доступа к частым командам
- Когда пользователю нужна постоянная панель

**Пример в чате:**
```

Bot: Вот топовые инструменты для vibe-coding:
```

## 🧠 Автоматическая генерация UI

### Триггеры генерации

Система автоматически генерирует UI элементы при обнаружении ключевых слов:

| Ключевые слова | Генерируемый UI |
|---|---|
| `обуч`, `курс`, `изуч` | Меню с темами обучения |
| `пример`, `покажи код` | Кнопки "Показать пример", "Объяснить" |
| `инструмент`, `фреймворк`, `установ` | Reply клавиатура с инструментами |
| `помощь`, `не понял`, `ошибка` | Кнопки помощи + ссылка на docs |
| `демо`, `попробова` | Web App кнопка |

## 🎯 Обработка callback'ов

Когда пользователь нажимает на кнопку, срабатывает action `HANDLE_TELEGRAM_CALLBACK`:

```typescript
// Автоматически обрабатывается в telegram-ui-plugin.ts

switch (callbackData) {
  case 'learn_vibe_basics':
    responseText = `⚡️ Vibe-coding основы...`;
    uiElements = [
      { type: 'inline_callback', text: '🚀 Да, начнём!', callback_data: 'start_course' }
    ];
    break;

  case 'learn_typescript':
    responseText = `🔥 TypeScript продвинутый...`;
    uiElements = [
      { type: 'inline_callback', text: 'Generics', callback_data: 'ts_generics' }
    ];
    break;
}
```

## 📊 Архитектура системы

```
┌─────────────────────────────────────────┐
│  Пользователь пишет сообщение          │
└────────────┬────────────────────────────┘
             │
             ▼
┌─────────────────────────────────────────┐
│  ElizaOS обрабатывает сообщение        │
└────────────┬────────────────────────────┘
             │
             ▼
┌─────────────────────────────────────────┐
│  Action: GENERATE_TELEGRAM_UI          │
│  - Анализирует текст                    │
│  - Детектит контекст                    │
│  - Генерирует UI элементы               │
└────────────┬────────────────────────────┘
             │
             ▼
┌─────────────────────────────────────────┐
│  TelegramUIHelper.sendMessageWithUI    │
│  - Конвертирует в Telegram Markup       │
│  - Отправляет с кнопками                │
└────────────┬────────────────────────────┘
             │
             ▼
┌─────────────────────────────────────────┐
│  Пользователь видит интерактивный UI   │
└─────────────────────────────────────────┘
             │
             ▼ (нажал кнопку)
┌─────────────────────────────────────────┐
│  Action: HANDLE_TELEGRAM_CALLBACK      │
│  - Обрабатывает callback_data           │
│  - Генерирует новый ответ               │
│  - Может добавить новые UI элементы     │
└─────────────────────────────────────────┘
```

## 🛠 Как добавить новые UI паттерны

### Шаг 1: Добавить детектор в `TelegramUIGenerator.generateUI()`

```typescript
// src/telegram-ui-plugin.ts

// Добавляем новый паттерн
if (lowerText.includes('показ') && lowerText.includes('статистик')) {
  elements.push({
    type: 'menu',
    title: '📊 Статистика:',
    options: [
      { text: '📈 Мой прогресс', callback_data: 'stats_progress' },
      { text: '🏆 Достижения', callback_data: 'stats_achievements' },
      { text: '📅 История', callback_data: 'stats_history' }
    ]
  });
}
```

### Шаг 2: Добавить обработчик в `handleCallbackAction`

```typescript
case 'stats_progress':
  responseText = `📈 Твой прогресс:\n• Изучено тем: 5\n• Выполнено заданий: 12`;
  uiElements = [
    { type: 'inline_callback', text: '📊 Подробнее', callback_data: 'stats_detailed' }
  ];
  break;
```

## 🎨 Стилизация кнопок

### Используем эмодзи для визуальной иерархии:

- **🚀** - Главное действие (начать, запустить)
- **📚** - Обучение, документация
- **🔧** - Инструменты, настройки
- **💬** - Общение, помощь
- **🎮** - Интерактивные демо
- **📊** - Статистика, аналитика
- **✅** - Подтверждение
- **❌** - Отмена
