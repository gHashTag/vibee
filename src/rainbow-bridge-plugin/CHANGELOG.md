# Changelog

All notable changes to the Rainbow Bridge plugin will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-11-12

### Added
- 🌈 Initial release of Rainbow Bridge plugin
- Autonomous E2E testing via Telegram MTProto
- RainbowBridgeService for test execution
- Test scenario definition and execution
- Comprehensive test reporting
- CI/CD integration support
- Automatic session validation
- Python scripts for Telegram authentication
- TypeScript types and interfaces
- Comprehensive documentation
- MIT License

### Features
- Send messages to bot autonomously
- Run test suites with multiple scenarios
- Generate detailed test reports
- Support for critical path testing
- Auto-run tests on startup (optional)
- Environment variable configuration
- Vitest-based unit tests

### Documentation
- Complete README with quick start
- API reference
- Best practices guide
- Troubleshooting section
- CI/CD integration examples
- Architecture overview
