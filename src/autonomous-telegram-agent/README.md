# 🌈 РАДУЖНЫЙ МОСТ - Autonomous Telegram User-Agent Plugin

**Autonomous Telegram User-Agent** for ElizaOS - enables your bot to send messages TO OTHER BOTS from user's account. This unlocks fully autonomous testing, monitoring, and interaction capabilities.

## Features

✨ **Autonomous Message Sending** - Send messages to any Telegram bot from user account
✨ **Response Reading** - Read bot responses and analyze conversations
✨ **One-Time Auth** - StringSession authentication (setup once, works forever)
✨ **Self-Testing** - Bots can test themselves autonomously
✨ **No User Intervention** - Fully automated after initial setup

## Why This Plugin?

Normal Telegram bots **CANNOT send messages to other bots**. The Bot API restriction prevents bots from initiating conversations with other bots. This plugin solves that by using **Telegram's User API (MTProto)** via Telethon.

### Use Cases

- 🤖 **Autonomous Self-Testing**: Bot sends `/selftest` to itself and validates responses
- 📊 **Bot Monitoring**: Automatically check if your bots are responding correctly
- 🔄 **Cross-Bot Communication**: Enable bot-to-bot workflows
- 🧪 **Automated Testing**: CI/CD integration for bot testing
- 🛠️ **Development Workflows**: Test new features autonomously

## Installation

### 1. Install Dependencies

```bash
# Python dependencies (for userbot)
pip3 install telethon python-dotenv

# Or with requirements.txt
pip3 install -r scripts/requirements.txt
```

### 2. Get Telegram API Credentials

1. Go to https://my.telegram.org/apps
2. Create new application
3. Save `api_id` and `api_hash`

### 3. Create Session (One-Time)

```bash
# Run authentication script
python3 scripts/autonomous-telegram-auth.py
```

This will:
- Ask for your phone number
- Send you a code via Telegram
- Ask for 2FA password (if enabled)
- Generate permanent `TELEGRAM_SESSION_STRING`
- Save it to `.env` automatically

### 4. Configure Environment

Add to your `.env`:

```bash
TELEGRAM_API_ID=12345678
TELEGRAM_API_HASH=your_api_hash_here
TELEGRAM_SESSION_STRING=1AgAOMTQ5... # Generated by auth script
```

### 5. Add Plugin to Character

```typescript
import { autonomousTelegramAgentPlugin } from '@/autonomous-telegram-agent';

export const projectAgent: ProjectAgent = {
  character,
  plugins: [
    autonomousTelegramAgentPlugin,
    // ... other plugins
  ],
};
```

## Usage

### Programmatic Usage

```typescript
import { TelegramUserAgentService } from '@/autonomous-telegram-agent';

// Get service from runtime
const userAgentService = runtime.getService('telegram-user-agent') as TelegramUserAgentService;

// Send message to bot
const result = await userAgentService.sendMessage({
  username: 'agent_vibecoder_bot',
  message: '/selftest',
  waitForResponse: true,
  timeout: 10000,
});

if (result.success) {
  console.log('Bot response:', result.response);
}

// Read messages from bot
const messages = await userAgentService.readMessages({
  username: 'agent_vibecoder_bot',
  limit: 10,
  onlyIncoming: true,
});

console.log('Recent messages:', messages.messages);
```

### Via Actions (Conversation)

The plugin includes two actions that can be triggered in conversation:

**Send Message:**

**Read Messages:**
```

```

### CLI Usage (Direct)

You can also use the Python scripts directly:

```bash

python3 scripts/autonomous-telegram-bot.py send-message "@agent_vibecoder_bot" "/selftest"

# Read messages
python3 scripts/autonomous-telegram-bot.py read-messages "@agent_vibecoder_bot" 10

# Validate session
python3 scripts/autonomous-telegram-bot.py validate-session
```

## Architecture

### Components

```
autonomous-telegram-agent/
├── index.ts                          # Plugin export
├── types.ts                          # TypeScript interfaces
├── services/
│   └── TelegramUserAgentService.ts   # Main service (wraps Python)
└── actions/
    ├── send-message-action.ts        # Send message action
    └── read-messages-action.ts       # Read messages action
```

### How It Works

1. **Service Layer** (`TelegramUserAgentService`)
   - Manages session lifecycle
   - Wraps Python Telethon scripts via `child_process`
   - Validates session on startup
   - Provides clean TypeScript API

2. **Python Scripts** (`scripts/autonomous-telegram-bot.py`)
   - Uses Telethon (MTProto) to connect as USER
   - Sends messages from user account
   - Reads bot responses
   - Returns structured output

3. **Actions** (`send-message-action.ts`, `read-messages-action.ts`)
   - Expose functionality via ElizaOS actions
   - Enable conversation-based interaction
   - Handle validation and error messages

### Session Management

- **StringSession**: Persistent authentication token
- **One-Time Setup**: Auth once, works forever (until you revoke)
- **Secure Storage**: Session string stored in `.env` (never commit!)
- **Validation**: Service checks session on startup

## API Reference

### TelegramUserAgentService

#### `sendMessage(options)`

Send message to a Telegram bot.

```typescript
await service.sendMessage({
  username: 'bot_username',      // Bot username (without @)
  message: 'message text',       // Text to send
  waitForResponse: true,         // Wait for bot response (default: true)
  timeout: 10000,                // Timeout in ms (default: 30000)
});
```

**Returns:**
```typescript
{
  success: boolean;
  response?: TelegramMessage[];  // Bot's response messages
  error?: string;
}
```

#### `readMessages(options)`

Read messages from a bot conversation.

```typescript
await service.readMessages({
  username: 'bot_username',      // Bot username (without @)
  limit: 10,                     // Max messages (default: 10)
  onlyIncoming: true,            // Only bot messages (default: true)
});
```

**Returns:**
```typescript
{
  success: boolean;
  messages?: TelegramMessage[];  // Array of messages
  error?: string;
}
```

#### `getSessionStatus()`

Get current session status.

```typescript
const status = service.getSessionStatus();
// {
//   isConfigured: boolean,
//   isValid: boolean,
//   lastChecked?: Date
// }
```

## Security Notes

⚠️ **IMPORTANT SECURITY CONSIDERATIONS:**

1. **Session String is Sensitive**: Treat `TELEGRAM_SESSION_STRING` like a password. Anyone with this can access your Telegram account.

2. **Never Commit `.env`**: Make sure `.env` is in `.gitignore`

3. **Revoke Access**: If compromised, go to Telegram Settings → Privacy → Active Sessions and terminate the session.

4. **2FA Recommended**: Enable Two-Factor Authentication on your Telegram account.

5. **Scope Limitation**: The session only has permissions of your user account. It cannot access admin functions of bots you own.

## Troubleshooting

### Session Invalid

```
❌ Session invalid
```

**Solution**: Run auth script again to create new session:
```bash
python3 scripts/autonomous-telegram-auth.py
```

### Python Script Timeout

```
❌ Command timed out
```

**Solutions**:
- Check internet connection
- Verify Telegram is not blocking your IP
- Increase timeout in `sendMessage()` options

### Bot Not Responding

```
⚠️ Ответ не получен (возможно бот ещё не запущен)
```

**Solutions**:
- Make sure target bot is running
- Increase wait time in Python script (edit `asyncio.sleep(3)` in `autonomous-telegram-bot.py`)
- Check bot logs for errors

### "Entity not found"

```
❌ Could not find the input entity for "@bot_username"
```

**Solutions**:
- Make sure you've started conversation with bot in Telegram first
- Check username spelling (no @ prefix in code)
- Try searching for bot in Telegram client first

## Examples

### Self-Testing Bot

```typescript
// In your bot's code
import { TelegramUserAgentService } from '@/autonomous-telegram-agent';

async function runSelfTest(runtime: IAgentRuntime) {
  const userAgent = runtime.getService('telegram-user-agent') as TelegramUserAgentService;

  // Send selftest command to self
  const result = await userAgent.sendMessage({
    username: 'agent_vibecoder_bot', // Your own bot username
    message: '/selftest',
    waitForResponse: true,
  });

  if (result.success) {
    // Analyze response
    const responseText = result.response?.map(m => m.text).join(' ');

    if (responseText?.includes('✅')) {
      console.log('✅ Self-test passed!');
    } else {
      console.log('❌ Self-test failed!');
    }
  }
}

// Schedule autonomous tests
setInterval(() => runSelfTest(runtime), 60 * 60 * 1000); // Every hour
```

### Cross-Bot Workflow

```typescript
// Bot A sends data to Bot B, Bot B processes and responds
const botA = runtime.getService('telegram-user-agent') as TelegramUserAgentService;

// Step 1: Send data to Bot B
await botA.sendMessage({
  username: 'data_processor_bot',
  message: '/process {"data": [1,2,3]}',
});

// Step 2: Read Bot B's response
await new Promise(resolve => setTimeout(resolve, 2000)); // Wait for processing

const result = await botA.readMessages({
  username: 'data_processor_bot',
  limit: 1,
});

console.log('Processed result:', result.messages?.[0].text);
```
