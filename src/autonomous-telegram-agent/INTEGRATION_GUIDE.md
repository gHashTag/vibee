# Integration Guide - Autonomous Telegram Agent

Quick guide to integrate the Autonomous Telegram User-Agent plugin into your ElizaOS project.

## Step-by-Step Integration

### 1. Setup Authentication (One-Time)

```bash
# Install Python dependencies
pip3 install telethon python-dotenv

# Run authentication script
python3 scripts/autonomous-telegram-auth.py
```

Follow the prompts:
- Enter your phone number (with country code)
- Enter code from Telegram
- Enter 2FA password (if enabled)

The script will automatically save `TELEGRAM_SESSION_STRING` to your `.env` file.

### 2. Configure Environment

Verify your `.env` has these variables:

```bash
TELEGRAM_API_ID=12345678
TELEGRAM_API_HASH=abcdef123456...
TELEGRAM_SESSION_STRING=1AgAOMTQ5...  # Long string generated by auth script
```

### 3. Add Plugin to Character

**Option A: For existing projects**

Edit your `src/character.ts` or equivalent:

```typescript
import { autonomousTelegramAgentPlugin } from './autonomous-telegram-agent/index.ts';

export const character: Character = {
  // ... your character config

  plugins: [
    // ... your existing plugins
    autonomousTelegramAgentPlugin,
  ],
};
```

**Option B: For new projects**

```typescript
import { ProjectAgent } from '@elizaos/core';
import { autonomousTelegramAgentPlugin } from './autonomous-telegram-agent/index.ts';
import character from './character.ts';

export const projectAgent: ProjectAgent = {
  character,
  plugins: [
    autonomousTelegramAgentPlugin,
  ],
};
```

### 4. Verify Setup

Start your bot and check logs:

```bash
bun run dev
```

Look for:
```
🌈 [TelegramUserAgent] Initializing...
🌈 [TelegramUserAgent] Session validated!
🌈 [TelegramUserAgent] Ready for autonomous operations!
```

## Usage Examples

### Example 1: Autonomous Self-Testing

```typescript
import { TelegramUserAgentService } from './autonomous-telegram-agent';

// In your bot initialization or cron job
async function scheduledSelfTest(runtime: IAgentRuntime) {
  const userAgent = runtime.getService('telegram-user-agent') as TelegramUserAgentService;

  if (!userAgent) {
    console.error('TelegramUserAgent not available');
    return;
  }

  // Send /selftest to your own bot
  const result = await userAgent.sendMessage({
    username: 'your_bot_username',
    message: '/selftest',
    waitForResponse: true,
    timeout: 15000,
  });

  if (result.success) {
    console.log('✅ Self-test completed');
    console.log('Response:', result.response?.map(m => m.text).join('\n'));

    // Analyze results
    const passed = result.response?.some(m => m.text.includes('✅'));
    if (!passed) {
      // Trigger alerts, log to monitoring system, etc.
      console.error('❌ Self-test FAILED!');
    }
  }
}

// Run every hour
setInterval(() => scheduledSelfTest(runtime), 60 * 60 * 1000);
```

### Example 2: Bot-to-Bot Communication

```typescript
async function sendToDataProcessor(runtime: IAgentRuntime, data: any) {
  const userAgent = runtime.getService('telegram-user-agent') as TelegramUserAgentService;

  // Send data to processing bot
  await userAgent.sendMessage({
    username: 'data_processor_bot',
    message: JSON.stringify(data),
  });

  // Wait a bit for processing
  await new Promise(resolve => setTimeout(resolve, 3000));

  // Read result
  const result = await userAgent.readMessages({
    username: 'data_processor_bot',
    limit: 1,
  });

  return result.messages?.[0]?.text;
}
```

### Example 3: Monitoring Multiple Bots

```typescript
const BOTS_TO_MONITOR = [
  'bot1_username',
  'bot2_username',
  'bot3_username',
];

async function monitorBots(runtime: IAgentRuntime) {
  const userAgent = runtime.getService('telegram-user-agent') as TelegramUserAgentService;

  for (const botUsername of BOTS_TO_MONITOR) {
    // Send health check
    const result = await userAgent.sendMessage({
      username: botUsername,
      message: '/health',
      timeout: 5000,
    });

    if (!result.success) {
      console.error(`❌ Bot ${botUsername} not responding`);
      // Send alert
    } else {
      console.log(`✅ Bot ${botUsername} is healthy`);
    }

    // Don't spam - wait between checks
    await new Promise(resolve => setTimeout(resolve, 1000));
  }
}
```

## Troubleshooting

### "Session not valid"

1. Check `.env` has correct `TELEGRAM_SESSION_STRING`
2. Run `python3 scripts/autonomous-telegram-auth.py` again
3. Make sure you completed 2FA auth

### "Service not found"

1. Verify plugin is in character.plugins array
2. Check import path is correct
3. Restart bot after adding plugin

### "Python script timeout"

1. Increase timeout in `sendMessage()` options
2. Check internet connection
3. Verify target bot is running

### "Cannot find entity"

1. Start conversation with target bot in Telegram first
2. Make sure bot username is correct (no @ prefix in code)
3. Try with bot's numeric ID instead of username

### Custom Timeout

Increase timeout for slow bots:

```typescript
await userAgent.sendMessage({
  username: 'slow_bot',
  message: '/complex_operation',
  timeout: 60000, // 60 seconds
});
```

### Retry Logic

Add retry logic for reliability:

```typescript
async function sendWithRetry(
  userAgent: TelegramUserAgentService,
  options: SendMessageOptions,
  maxRetries = 3
) {
  for (let i = 0; i < maxRetries; i++) {
    const result = await userAgent.sendMessage(options);
    if (result.success) return result;

    // Wait before retry (exponential backoff)
    await new Promise(resolve => setTimeout(resolve, 1000 * Math.pow(2, i)));
  }

  throw new Error('Failed after max retries');
}
```

## Security Best Practices

1. **Never commit `.env`** - Add to `.gitignore`
2. **Rotate sessions periodically** - Re-run auth script every few months
3. **Use environment-specific sessions** - Different sessions for dev/prod
4. **Monitor session activity** - Check Telegram → Settings → Active Sessions
5. **Revoke if compromised** - Terminate session immediately if leaked
