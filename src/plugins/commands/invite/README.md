# Invite Command Plugin

Реферальная программа и система приглашений.

## Функции

- 👥 Реферальная программа
- 🔗 Генерация пригласительных ссылок
- 📊 Статистика приглашений
- 🎁 Система наград

## Команды

- `/invite` - Показать реферальную программу

## Использование

```typescript
import { createInviteCommand } from './invite';
```
