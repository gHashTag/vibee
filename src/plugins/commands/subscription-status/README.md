# Subscription Status Command Plugin

Просмотр статуса подписки пользователя.

## Функции

- 📋 Отображение текущего плана
- ⏰ Отслеживание срока действия
- 🔄 Управление автопродлением
- ✅ Список доступных функций

## Команды

- `/subscription` - Показать статус подписки

## Использование

```typescript
import { createSubscriptionStatusCommand } from './subscription-status';
```
