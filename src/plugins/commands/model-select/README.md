# Model Select Command Plugin

Выбор AI-модели для работы бота.

## Функции

- 🤖 Выбор AI-модели (Claude, GPT, Gemini)
- 📊 Сравнение моделей по параметрам
- ⚡ Оптимизация скорости и качества
- 💰 Контроль стоимости

## Команды

- `/model` - Выбрать AI-модель

## Использование

```typescript
import { createModelSelectCommand } from './model-select';
```
