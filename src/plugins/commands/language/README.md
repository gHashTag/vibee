# Language Command Plugin

Переключение языка интерфейса бота.

## Функции

- 🌐 Выбор языка интерфейса
- 🇷🇺 Поддержка русского и английского
- 🔄 Динамическое переключение

## Команды

- `/lang` - Выбрать язык
- `/lang ru` - Русский
- `/lang en` - English

## Использование

```typescript
import { createLanguageCommand } from './language';
```
