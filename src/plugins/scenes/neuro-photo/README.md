# NeuroPhoto Scene Plugin

🎨 **AI генерация изображений** с пошаговым мастером в Telegram

## Возможности

- 3 AI модели для генерации
- 5 стилей изображений
- 3 размера изображений
- Интерактивный мастер-класс
- Промпты с контекстом

## Структура

```
neuro-photo/
├── Scene.ts              # Wizard Scene с 4 шагами
├── types.ts              # Типы и константы
├── actions/
│   └── generateImage.action.ts  # Запуск генерации
├── services/
│   └── imageService.ts   # Сервис генерации
└── plugin.ts             # Главный плагин
```

## Использование

### Команды
- `/neurophoto` - запустить генератор
- `Нарисуй ...` - текстовый промпт
- `Создай картинку ...` - альтернативная команда

### Workflow

1. **Модель** - пользователь выбирает AI модель
2. **Стиль** - выбирает стиль изображения
3. **Размер** - выбирает разрешение
4. **Генерация** - создается изображение

## Пример работы

```
Пользователь: /neurophoto
Бот: 🎨 Выберите модель для генерации
     [SeedDream 4] [Flux Multi] [Nano Banana]

Пользователь: нажимает [SeedDream 4]
Бот: ✅ Выберите стиль изображения
     [Фотореализм] [Аниме] [Цифровое искусство]

... и так далее
```

## Технические детали

- Использует FAL API для генерации
- Telegraf Scenes для wizard-интерфейса
- Интеграция с ElizaOS runtime
- Сохранение промптов в памяти

## Требования

- `FAL_KEY` в переменных окружения
- `REPLICATE_API_KEY` как резерв (опционально)
