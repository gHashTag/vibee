# Text to Speech Scene Plugin

🎙️ **Преобразование текста в речь** с выбором голоса

## Возможности

- 6 голосов OpenAI
- Регулировка скорости
- 4 аудио формата
- Высокое качество
- Base64 аудио

## Workflow

1. **Текст** - ввод текста (до 1000 символов)
2. **Голос** - выбор из 6 голосов
3. **Скорость** - регулировка от 0.5x до 2.0x
4. **Генерация** - создание аудио

## Голоса

- 🎭 Alloy - нейтральный стандарт
- 🎤 Echo - глубокий мужской
- 🗣️ Fable - британский акцент
- 🔊 Onyx - громкий премиум
- 🎀 Nova - мягкий женский
- ✨ Shimmer - звонкий

## Использование

```
Пользователь: /tts
Бот: 📝 Введите текст
Пользователь: Привет, как дела?
Бот: 🎭 Выберите голос
     [Alloy] [Echo] [Fable] ...

... результат: аудио файл
```
