# Avatar Voice Scene Plugin

🎤 **Настройка голоса** для AI-аватаров

## Возможности

- 6 голосов (мужские/женские)
- 5 языков
- 6 эмоций
- Сохранение конфигурации
- OpenAI TTS

## Workflow

1. **ID** - ввод ID аватара
2. **Голос** - выбор из 6 вариантов
3. **Язык** - выбор языка озвучивания
4. **Эмоция** - эмоциональный тон
5. **Сохранение** - конфигурация готова

## Голоса

- 🎭 Alloy - нейтральный
- 🎤 Echo - глубокий мужской
- 🗣️ Fable - британский акцент
- 🔊 Onyx - громкий и четкий
- 🎀 Nova - мягкий женский
- ✨ Shimmer - звонкий женский

## Использование

```
Пользователь: /voice
Бот: 📝 Введите ID аватара
Пользователь: my_assistant
Бот: 🎭 Выберите голос
     [Alloy] [Echo] [Fable] ...

... результат: конфигурация голоса
```
