# Avatar Brain Scene Plugin

🧠 **Создание "мозга" аватара** с полной настройкой личности

## Возможности

- 8 черт характера
- 5 стилей общения
- 8 областей экспертизы
- 8 категорий интересов
- Генерация JSON-конфигурации
- GPT-4 для создания персонажа

## Workflow

1. **ID** - ввод идентификатора аватара
2. **Черты** - выбор до 5 черт личности
3. **Стиль** - стиль общения
4. **Экспертиза** - области знаний
5. **Интересы** - личные интересы
6. **Создание** - генерация конфигурации

## Использование

```
Пользователь: /brain
Бот: 📝 Введите ID аватара
Пользователь: my_assistant
Бот: 🎭 Выберите черты характера
     [😊 Дружелюбный] [💼 Профессиональный] ...

... результат: JSON конфигурация мозга
```
