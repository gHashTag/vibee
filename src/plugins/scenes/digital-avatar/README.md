# Digital Avatar Scene Plugin

🤖 **Создание цифрового аватара** из ваших фотографий

## Возможности

- Загрузка 1-5 фотографий
- 3 варианта пола
- 4 возрастных категории
- 5 стилей аватара
- 6 типов фона
- AI обработка изображений

## Структура

```
digital-avatar/
├── Scene.ts                  # Wizard Scene с 6 шагами
├── types.ts                  # Типы и константы
├── actions/
│   └── createAvatar.action.ts   # Запуск создания аватара
├── services/
│   └── avatarService.ts         # Сервис создания аватара
└── plugin.ts                   # Главный плагин
```

## Workflow

1. **Фото** - загрузка 1-5 фотографий
2. **Пол** - выбор пола
3. **Возраст** - возрастная категория
4. **Стиль** - визуальный стиль (реализм, аниме, киберпанк и т.д.)
5. **Фон** - выбор фона
6. **Создание** - генерация аватара

## Использование

```
Пользователь: /avatar
Бот: 📸 Отправьте 1-5 фотографий себя
     [✅ Готово]

Пользователь: [загружает фото] → [✅ Готово]
Бот: 👤 Выберите пол
     [👨 Мужской] [👩 Женский] [🧑 Не указывать]

... и так далее
```

## Технические детали

- FAL AI для генерации
- Telegraf Scenes для wizard
- Обработка множественных фото
- Сохранение настроек в сессии
