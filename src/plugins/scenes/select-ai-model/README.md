# Select AI Model Scene Plugin

⚙️ **Выбор AI моделей** для разных задач

## Возможности

- 5 категорий моделей
- Фильтрация по параметрам
- Сравнение моделей
- Рекомендации
- Детальная информация

## Workflow

1. **Категория** - выбор типа задач
2. **Скорость** - приоритет производительности
3. **Качество** - уровень качества
4. **Рекомендации** - выбор модели

## Категории

- 🎨 Изображения - генерация и редактирование
- 📝 Текст - создание и анализ
- 🎤 Голос - синтез речи
- 🎬 Видео - создание видео
- 🧠 Мультимодальные - понимание

## Использование

```
Пользователь: /models
Бот: 🎯 Выберите категорию задач
     [🎨 Изображения] [📝 Текст] ...

Пользователь: [выбирает] → [настраивает приоритеты]
Бот: ✨ Рекомендуемая модель
     Flux Pro
     ⭐⭐⭐⭐⭐ качество | ⚡⚡⚡⚡ скорость
     ✅ Использовать | 🔍 Показать все
```
