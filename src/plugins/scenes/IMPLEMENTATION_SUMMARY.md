## 🏗️ Архитектура

### Типы и интерфейсы (`types.ts`)
```typescript
interface SceneContext {
  session: {
    wizardData: Record<string, any>;
  };
}

interface ScenePlugin {
  scene: Scenes.WizardScene<SceneContext> | Scenes.BaseScene<SceneContext>;
}

interface PaymentPlan {
  id: string;
  name: string;
  price: number;
  currency: 'RUB' | 'STARS';
  features: string[];
  description: string;
}

interface BalanceData {
  userId: string;
  rubles: number;
  stars: number;
  subscription?: {
    plan: string;
    expiresAt: number;
  };
  history: Array<{
    type: 'payment' | 'refund' | 'subscription' | 'spend';
    amount: number;
    currency: 'RUB' | 'STARS';
    description: string;
    date: number;
  }>;
}
```

### Plugin сервис (`scenes-plugin.ts`)
- **ScenesService** - главный сервис для управления сценами
- Регистрация всех сцен в `Stage`
- Интеграция с Telegram Bot API
- Команды для перехода к сценам
- Автоматическая инициализация
