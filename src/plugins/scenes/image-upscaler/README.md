# Image Upscaler Scene Plugin

⬆️ **Улучшение и увеличение изображений** с помощью AI

## Возможности

- Увеличение до 8x
- 4 AI модели
- 5 типов улучшений
- 3 формата вывода
- Real-ESRGAN, Swin2SR, ESRGAN

## Workflow

1. **Изображение** - загрузка картинки
2. **Увеличение** - выбор коэффициента (2x-8x)
3. **Улучшения** - тип улучшения
4. **Модель** - выбор AI модели
5. **Генерация** - создание улучшенного изображения

## Модели

- 📸 Real-ESRGAN - лучший для фото
- ⚡ Swin2SR - универсальный
- 🎯 ESRGAN - классический
- 🎨 Latent Upscaler - AI стилизация

## Улучшения

- 🚫 Без улучшений
- 🔍 Повышение резкости
- 🧹 Шумоподавление
- 🎨 Цветокоррекция
- ✨ Высокое качество

## Использование

```
Пользователь: /upscale + [изображение]
Бот: ⬆️ Выберите коэффициент увеличения
     [2x] [3x] [4x] [8x]

... результат: улучшенное изображение
```

## Технические детали

- FAL AI для апскейла
- Поддержка JPG, PNG, WebP
- Максимум 10MB
- Базова64 вывод
