# Image to Prompt Scene Plugin

🔍 **Анализ изображений** и создание AI промптов

## Возможности

- 4 типа анализа (базовый, детальный, художественный, фотографический)
- 5 стилей промптов
- 5 цветовых гамм
- OpenAI Vision API
- Автоматическое создание промптов

## Workflow

1. **Изображение** - загрузка картинки
2. **Тип анализа** - выбор метода анализа
3. **Стиль** - стиль создания промпта
4. **Цвета** - цветовая схема
5. **Генерация** - анализ + создание промпта

## Использование

```
Пользователь: /analyze + [изображение]
Бот: 🔍 Выберите тип анализа
     [📝 Базовый] [🔍 Детальный] [🎨 Худ.] [📸 Фото]

... результат: описание + готовый промпт
```

## Технические детали

- OpenAI Vision API (GPT-4o)
- Гибкие промпты
- Анализ композиции и стиля
- Сохранение в памяти
