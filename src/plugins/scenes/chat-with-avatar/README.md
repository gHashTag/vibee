# Chat with Avatar Scene Plugin

💬 **Интерактивный чат** с AI-аватарами

## Возможности

- 5 режимов общения
- 4 уровня креативности
- Быстрые вопросы
- Сохранение истории
- Загрузка мозга аватара
- OpenAI GPT-4

## Workflow

1. **Аватар** - выбор из предустановленных или свой ID
2. **Режим** - стиль общения
3. **Креативность** - уровень творчества
4. **Чат** - интерактивное общение

## Использование

```
Пользователь: /chat
Бот: 🤖 Выберите аватара
     [MyAssistant] [CreativeBot] [TechGuru] ...

Пользователь: [выбирает] → [настраивает режим]
Бот: ✨ Чат начат!
     1. Как дела?
     2. Расскажи о себе
     ...

Пользователь: 1. Как дела?
Бот: 🤖 Привет! У меня все отлично...
```

## Режимы

- 💬 Дружеский - непринужденная беседа
- 💼 Деловой - серьезный разговор
- 🎨 Креативный - мозговой штурм
- 🎓 Обучение - объяснения
- 🎮 Развлечения - игры и юмор

## Технические детали

- GPT-4 для генерации
- Сохранение истории в сессии
- Поддержка brain_config
- Быстрые команды
- Inline клавиатуры
